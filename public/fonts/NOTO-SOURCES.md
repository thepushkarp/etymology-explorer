# Noto script fonts

Retrieved 2026-11-10 from the official Google Fonts CSS API. These are the
unmodified WOFF2 script subsets served for regular weight 400. The application
self-hosts them; it makes no request to Google Fonts at runtime. Each family is
licensed under SIL Open Font License 1.1; the complete license is included beside
the font. Latin and Latin Extended subsets are deliberately not included.

CSS source: https://fonts.googleapis.com/css2?family=Noto+Serif+Devanagari:wght@400&family=Noto+Nastaliq+Urdu:wght@400&display=swap
